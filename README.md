# 中南财人文社科论文写作助手

面向**本科阶段**的人文社科与经管类论文写作技能。WPS Comate 技能开发大赛（初级赛道·技能开发）参赛作品。

服务范围限定在课程论文、学年论文、毕业论文（含开题报告），不处理硕博论文与期刊投稿。

## 解决什么问题

本科生写论文的真实卡点不在"不会写字"，而在四个判断上反复出错：

1. **选题空转**——题目看起来大，实际找不到证据支撑
2. **理论与材料脱节**——理论章节单独背概念，分析章节另起炉灶
3. **章节之间没逻辑**——每一节单独看都对，连起来读不通
4. **引注与查重踩坑**——体例不统一、直接引用未标注、参考文献格式混乱

本技能把这四类判断拆成可执行的检查项，而不是给一段泛泛的写作建议。

## 构成

| 部分 | 内容 | 说明 |
|---|---|---|
| `SKILL.md` | 技能定义 | 自包含、零依赖，可直接粘贴进 Comate 平台运行。含防幻觉红线、六类研究范式路由、本科四关流程、真实文献检索流程、提交前 30 条自检 |
| `知识库/K1–K5` | 校情与判据 | 本校学院与专业方向清单、引注体例对照表、学术不端类型与判定要点、数据源清单与接入规范、选题与证据判据 |
| `repo/` | 工程版实现 | 同一套判据的可运行版本，用于验证技能里写的检查项不是纯文字约定 |

## 工程版用法

```bash
cd repo
pip install -r requirements.txt

python skill.py check  论文片段.md        # 文本检测（22 条规则，也直接读 .docx）
python skill.py sources                   # 数据源清单与实测状态
python skill.py find   --source arxiv --q "asset pricing" --cat q-fin.PM
python skill.py quote  --code sh600519
python skill.py macro  --indicator NY.GDP.MKTP.CD
python skill.py cites  知网导出.txt        # 解析题录（EndNote / RefWorks / GB-T）
python skill.py panel  资产负债表.csv      # CSMAR 数据画像
```

网络不通时加 `--direct`（绕代理）或 `--skip-verify`（跳证书校验，仅调试）。

## 设计取舍

- **防幻觉优先**：所有文献必须来自真实检索结果，不生成不存在的参考文献。技能里对此设了硬性红线，而非"建议"。
- **按范式分流**：哲学与马理论、社会学、政治学、经济学、金融学、法学等各自的研究范式不同，检查项也不同；技能先判范式再给判据，避免用一套标准套所有学科。
- **校情内嵌**：学院归属、专业方向、引注体例按本校口径写进知识库，减少"通用建议对不上本校要求"的偏差。
