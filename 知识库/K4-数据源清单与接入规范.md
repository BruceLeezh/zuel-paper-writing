# K4-数据源清单与接入规范

> 用途：学生问"我这个题目该用什么数据""这个数据去哪下""能不能直接抓"时，按本表回答。
> 原则：**先分清访问等级，再谈能不能自动化**。不区分等级的"数据源清单"会误导学生去抓不该抓的库。

---

## 一、五个访问等级（必须先判级）

| 等级 | 含义 | 能不能写代码自动取 | 典型源 |
|:---:|---|---|---|
| **A** | 公开开放，无需认证，条款允许程序化访问 | 可以，遵守限流 | OpenAlex、Crossref、世界银行、arXiv |
| **B** | 免费注册后拿 Key，有明确配额 | 可以，需在 .env 配 Key | CORE、FRED、Tushare |
| **C** | 机构订阅或商务合作，个人无独立入口 | **不可以自动抓取**，只能"用户导出 → AI 解析" | 知网、万方、CSMAR、Wind |
| **D** | 网页公开但无官方 API、无授权承诺 | **不做循环抓取**，仅限用户手动复制或单次请求 | 东方财富行情页、裁判文书网 |
| **M** | 手动导出格式 | 不联网，只解析用户给的文件 | 知网 EndNote、RefWorks、GB/T 7714 文本 |

**一句话判据**：需要登录态、需要付费、或服务条款禁止自动访问的，都不进自动化通道。这不只是合规问题——这类抓取本来就不稳定，跑一晚上断三次，论文写不完。

---

## 一·补 实测结论（2026-10-20，本机逐个探测）

清单写了 34 个源，但"列在表上"和"真能取到"是两件事。下面是实测结果，只认实测。

| 源 | 实测 | 现象 |
|---|:---:|---|
| OpenAlex | 通 | 200，返回 28KB JSON（无 Key 时与他人共享日预算） |
| Crossref | 通 | 200，返回 JSON，total-results 正常 |
| arXiv | 通 | 200，Atom XML；本机需处理证书链（见下） |
| World Bank | 通 | 200，`[meta, rows]` 结构 |
| 东方财富 | 时通时断 | 曾取到 200 单只快照；复测被拒（RemoteDisconnected）。字段为原始整数，价格需按接口约定换算 |
| 新浪财经 | 通 | 200，**GBK 编码**，必须带 Referer |
| Semantic Scholar | 限流 | 429，无 Key 时配额被共享 |
| 国家统计局 | 拒 | 403，带浏览器 UA 与 Referer 仍拒绝 |
| IMF / BIS | 拒 | 403 / 406（后者缺 Accept 头） |
| DOAJ / CORE | 不通 | 当前网络 SSL 握手超时；CORE 另需 Key |
| 知网 / 万方 / 维普 / CSMAR / Wind / iFinD | 不可自动 | 需机构订阅与登录态 |
| 国家法律法规数据库 | 无接口 | 返回的是前端应用外壳，接口未公开文档化 |
| 裁判文书网 / 庭审公开网 | 无接口 | 需人机验证，反爬严格 |

**结论**：真正能"直接爬"的只有 6 个——OpenAlex、Crossref、arXiv、World Bank、新浪（5 个稳定），以及东方财富（非官方接口，时通时断）。其余要么要 Key，要么需人工。

### 报错与对策

| 报错 | 说明 | 对策 |
|---|---|---|
| `502 Tunnel connection failed` | 本机代理转发失败 | 直连：`--direct` |
| `CERTIFICATE_VERIFY_FAILED` | Python 缺根证书（Windows 常见） | `pip install certifi`；临时调试可 `--skip-verify` |
| `429` | 被限流 | 配免费 Key，或降低频率 |
| `403` | 站点拒绝脚本 | 改网页导出，别硬试 |
| `timed out` | 网络不可达 | 换网络或走代理 |

## 二、学术文献类

| 源 | 覆盖领域 | 获取方式 | 格式 | 可获取范围 |
|---|---|---|---|---|
| **OpenAlex** | 全学科文献元数据（2.5 亿+ 作品、作者、机构、引文网络） | REST，`api.openalex.org`，无需 Key；填 email 进 polite pool | JSON | 题录、摘要、被引关系；**不含全文** |
| **Crossref** | DOI 注册元数据：期刊论文、图书、会议、数据集 | REST，`api.crossref.org`，无需 Key | JSON | 题录 + DOI + 部分摘要；含参考文献列表 |
| **Semantic Scholar** | 全学科，AI 增强（引用上下文、TLDR 摘要） | REST，免费 Key 可选，有 Key 配额更高 | JSON | 题录、摘要、引用上下文 |
| **CORE** | 开放获取全文（3 亿+） | REST，需免费注册 Key | JSON + PDF 链接 | 题录 + **可拿全文**，是四个源里唯一能批量取正文的 |
| **arXiv** | 预印本：数学、统计、经济（econ.GN/ECON）、金融、计算机 | 官方 API，无需 Key | Atom XML | 题录 + 全文 PDF |
| **DOAJ** | 开放获取期刊目录 | REST，无需 Key | JSON | 期刊与文章题录 |
| **国家哲学社会科学文献中心**（NCPSSD） | 中文社科期刊、论文 | 免费注册，网页检索，无正式 API | 网页 / 手工复制 | 题录 + 部分全文；中文社科最实用的免费源 |
| **知网 CNKI** | 中文学术全文库（期刊、学位论文、会议、报纸、年鉴） | **机构订阅**。图书馆入口登录；知网研学开放平台 `openx.cnki.net` 另有 OAuth2/JWT 数据 API，但需申请成为生态伙伴，个人不能即开即用 | CAJ/PDF 全文；题录可导出 EndNote、RefWorks、NoteExpress、GB/T 7714 | 全文受订阅范围限制；题录无限但导出有条数上限 |
| **万方** | 中文期刊、学位论文、会议、专利、标准 | 机构订阅 | PDF；题录可导出 | 同上 |
| **维普** | 中文期刊为主 | 机构订阅 | PDF | 同上 |
| **读秀** | 图书、图书章节（可查目录与部分页） | 机构订阅 | 网页 / 文献传递 | 图书章节级检索，适合找专著页码 |

**知网怎么接才合规**：不做网页抓取。正确链路是「学生用图书馆账号检索 → 勾选 → 导出题录（EndNote 或 GB/T 7714）→ 把导出文本交给 AI 解析」。技能负责解析、去重、按文献矩阵归类，不负责下载。

## 三、财经行情与公司数据

| 源 | 覆盖领域 | 获取方式 | 格式 | 可获取范围 |
|---|---|---|---|---|
| **东方财富** | A 股/港股/美股行情、财务报表、公告、基金、可转债 | 网页端有 JSON 接口（行情、财务报表快照），**非官方、无文档、无 SLA**；官方数据产品为 Choice 终端（付费订阅） | JSON（接口）/ Excel（数据中心导出） | 行情快照、历史 K 线、财务指标；**历史深度与频次受限，接口随时可能变** |
| **新浪财经** | A 股实时行情、历史日线 | 网页 JSON 接口，非官方 | JSON / 文本 | 实时报价、日线历史 |
| **腾讯财经** | A 股/港股行情 | 网页 JSON 接口，非官方 | JSON | 实时报价 |
| **AkShare** | 聚合器：把东财、新浪、同花顺等公开页封装成 Python 函数 | `pip install akshare`，开源库，无需 Key | pandas DataFrame | 覆盖面最广的开源方案，**但底层仍是 D 级接口，稳定性随数据提供方变化** |
| **Tushare** | A 股行情、财务、宏观、基金 | 注册积分制，免费额度有限 | JSON / DataFrame | 日线、财务三表、宏观；积分不够时受限 |
| **BaoStock** | A 股历史行情（免费） | 无需注册，Python 包 | DataFrame | 日线/分钟线历史，无实时 |
| **CSMAR** | 学术研究级公司财务、治理、ESG、审计 | **学校采购**，需在校园网或 VPN 内访问 | Excel / CSV 导出 | 研究级字段（应计、治理指数等），四源里最贴合实证论文 |
| **Wind / iFinD** | 全品类金融终端 | 终端订阅，账号绑机器 | Excel 插件 / API（机构付费） | 全市场数据；导出受账号权限限制 |

**东方财富怎么用才不出事**：写作时的正当用法是「在网页或客户端里查到、手工记录或导出 Excel」，或「用 AkShare 这类开源库低频取数」。**不要**写成循环批量抓取、不要绕过登录、不要把接口当成有 SLA 的数据源。论文里必须注明数据来源与获取日期。

### CSMAR 导出文件怎么接（本校实证论文首选）

CSMAR 是学校采购的，走的是导出文件，不是接口。导出后交给本技能，能拿到三样东西：数据画像、字段对照、可直接改的"数据来源与样本"段落。

**常用字段代码**（导出时常是英文代码，写作时要译回中文）：

| 代码 | 含义 | 代码 | 含义 |
|---|---|---|---|
| Stkcd | 股票代码 | Accper | 会计期间 |
| ShortName | 股票简称 | Typrep | 报表类型（A 合并 / B 母公司） |
| Indcd | 行业代码 | Listdt | 上市日期 |
| TotalAssets | 资产总计 | TotalLiab | 负债合计 |
| Revenue | 营业收入 | NetProfit | 净利润 |
| ROA / ROE | 总资产／净资产收益率 | Lev | 资产负债率 |
| Yretwd | 年个股回报率（考虑现金红利再投资） | Trddt | 交易日期 |

**六个一定会踩的坑**：

1. **Typrep 必须筛**。默认导出里 A（合并报表）和 B（母公司报表）都有，不筛样本量会翻倍，回归全错。
2. **文件头有说明行**。第一两行常是"本数据来源于 CSMAR"，直接当表头读会导致整表错位。
3. **缺失是空字符串，不是 0**。别用 0 填充，否则均值、回归系数全被污染。
4. **Accper 格式不统一**。有时 `2020-12-31`，有时 `20201231`，取年份要按正则提取而不是截字符串。
5. **重复行**。分批导出再合并时常出现重复，先查再算。
6. **字段缺失率高**。某些指标只在部分年度有，缺失率超过 30% 的字段要么换代理变量，要么在文中说明。

**导出后怎么用**：

```bash
python skill.py panel 资产负债表.csv
python skill.py verify 题录.txt
```

输出三块：观测数与字段数、时间跨度与公司数、高缺失与重复提示；字段代码对中文名；一段「数据来源与样本」骨架。**骨架里的剔除规则与最终 N 都是占位符**——没做的处理步骤不会被写成"已完成"。

## 六、统一接入方案（工程层）

### 6.1 适配器契约

所有源登记在同一条表里，字段名与工程版 `zuel/feeds.py` 的 `SOURCES` 一致：

```python
dict(
    name="openalex",        # 源标识，与命令行 --source 取值相同
    field="literature",     # literature | market | macro | law | policy
    level="A",              # A | B | C | D | M（访问等级，见第一节）
    auth=False,             # 是否需要 Key 或登录态
    adapter=True,           # 是否已实现可直接调用的适配器
    covers="…",             # 覆盖领域
    how="JSON REST",        # 获取方式与数据格式
    tested="直连成功",       # 逐源实测状态，不实测不写"可用"
)
```

### 6.2 统一记录模型

不同源的字段名、日期格式、作者写法都不一样，统一成一条记录再往外给。
字段与工程版 `zuel/model.py` 的 `Item` 一致：

```python
@dataclass
class Item:
    src: str               # 来源标识，如 openalex / sina / worldbank
    field: str             # literature | market | macro
    title: str
    people: list[str]      # 作者 / 机构，取不到就留空，不编
    when: str              # 年份或日期原样保留，不擅自改格式
    ident: str             # DOI / 股票代码 / 指标代码
    note: str              # 摘要或备注
    link: str              # 原始链接，便于复核
    pulled: str            # 取数日期（默认今天）——写论文要注明，缺了没法复现
    raw: dict              # 原始响应或解析余项，便于复核
```

`pulled` 不是可有可无的字段——实证论文的数据来源要写到“某库、某口径、某日期”，缺了它没法复现。

### 6.3 限流、缓存、降级

| 机制 | 规则 |
|---|---|
| 限流 | 进程内按站点节流：arXiv 3 秒/次（其官方建议），新浪、东方财富 1 秒/次（D 级只做单次查询，不写循环）；其余源不加固定间隔，遇 429 按 `Retry-After` 退避 |
| 缓存 | **不做磁盘缓存**。元数据会过期，缓存会把旧卷期页写进论文；需要留痕时把原始响应留在记录的 `raw` 字段里 |
| 降级 | 单个源超时 15 秒即放弃，其余源照常返回，结果里标注"该源不可用" |
| 失败提示 | 任一源失败必须显式告知用户，不许静默返回空列表（空列表会被误读成"没有文献"） |

### 6.4 合规红线

1. **C 级永不自动抓取**。知网、万方、CSMAR 只走"用户导出 → 解析"。
2. **D 级不写循环、不带 Cookie、不绕登录**。只用公开页面，低频、单次、用户显式触发。
3. **不存用户凭据**。`.env` 只放 API Key，不放账号密码与 Cookie。
4. **每条数据带 `pulled`（取数日期）**，便于论文标注与事后复核。

## 六·补 落地实现（包内 `repo/`）

工程版是这套判据的可运行实现，与技能本体放在同一个包里，本地可直接跑。

| 模块 | 职责 |
|---|---|
| `repo/zuel/model.py` | `Problem`（检测结果）／`Item`（统一记录）／`Level`（三级严重度） |
| `repo/zuel/net.py` | 取数：代理、证书、编码、8MB 响应上限、重定向守卫 |
| `repo/zuel/checker.py` | 文本检测：22 条确定性规则（另有 `SYS-01` 崩溃提示，不计入） |
| `repo/zuel/feeds.py` | **34 个源的登记表** + 文献／行情／宏观适配器 |
| `repo/zuel/tables.py` | 导出解析：题录（EndNote／RefWorks／GB-T）、CSMAR 面板 |
| `repo/zuel/verify.py` | 文献核验：DOI 查 Crossref，逐字段比对 |
| `repo/skill.py` | 统一命令入口（八条命令） |

```bash
cd repo
python skill.py sources                                    # 34 个源、五级模型、逐源实测状态
python skill.py find --source arxiv --q "asset pricing" --cat q-fin.PM
python skill.py find --source worldbank --q NY.GDP.MKTP.CD --country CN
python skill.py quote --code 600519
python skill.py cites 知网导出.txt
python skill.py panel 资产负债表.csv
python skill.py verify 题录.txt
```

需要绕过代理或证书时，在子命令后加 `--direct` / `--skip-verify`（后者仅在调试时使用，会打印警告）。

`panel` 除了给画像，还会做三件与实证论文直接相关的事：检出 `Typrep` 同时含合并与母公司两套报表时明确警告（不筛会让样本量翻倍）；列出缺失率≥30% 的字段；报出完全重复行。返回的“数据来源与样本”段落里，剔除规则与最终 N 一律留占位符，不代填。

**注意**：登记表里的 34 个源，只有 6 个实现了直接取数（OpenAlex、Crossref、arXiv、World Bank、新浪，以及时通时断的东方财富）。其余为能力登记——C 级的知网、CSMAR 走 `cites` / `panel` 解析导出文件，法律与政策类需人工检索。不实现的部分在 `tested` 字段里写明了原因。

## 七、六个典型场景的源组合

| 场景 | 推荐组合 | 不推荐 |
|---|---|---|
