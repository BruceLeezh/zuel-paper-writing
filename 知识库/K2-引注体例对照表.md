# K2-引注体例对照表

> 用途：判定用户论文的引注体例是否统一，并在需要时按正确格式给出条目。
> 原则：**先问清体例，再动手**。一篇论文内混用两种以上体例是最常见的格式硬伤。

## 一、先判断：这篇论文该用哪种体例

| 学科/场景 | 常用体例 | 判断依据 |
|-----------|---------|---------|
| 经济、金融、财政、会计、工商、公共管理 | 作者-年份（著者出版年制） | 正文写"（张三，2023）"，文末文献表按拼音排序 |
| 法学各方向 | 脚注 + 《法学引注手册》 | 页下注编号，连续编号，引用页码在脚注内 |
| 中国语言文学、哲学、历史类思辨 | 页下注或尾注（人文社科通例） | 注释体例见各刊稿约 |
| 新闻传播、社会学 | 作者-年份（APA 系）或 GB/T 7714 顺序编码 | 依目标期刊 |
| 本科毕业论文（全校通用底线） | GB/T 7714 或本科生院/学院下发的格式模板 | **以本科生院与学院当年发布的格式文件为准** |

**必问一句**："你们学院或导师要求哪种体例？如果有模板，按模板来。"模板优先于任何通用规范。

---

## 二、GB/T 7714（顺序编码制）常用条目

正文标注为上标方括号：`……的影响[1]`；多篇 `[1-3]`、`[1,4]`。

| 文献类型 | 格式 | 示例 |
|---------|------|------|
| 期刊论文 | 作者. 题名[J]. 刊名, 年, 卷(期): 起-止页. | 张三, 李四. 数字化转型与企业创新[J]. 经济研究, 2023, 58(4): 112-128. |
| 专著 | 作者. 书名[M]. 版本. 出版地: 出版社, 年: 引文页码. | 王五. 公司金融[M]. 3版. 北京: 中国人民大学出版社, 2022: 45-47. |
| 学位论文 | 作者. 题名[D]. 城市: 学校, 年. | 赵六. ESG 评级与融资成本[D]. 武汉: 中南财经政法大学, 2023. |
| 会议论文 | 作者. 题名[C]//论文集名. 出版地: 出版者, 年: 页码. | 钱七. 货币政策传导[C]//中国金融学年会论文集. 北京: 中国金融出版社, 2022: 88-95. |
| 报纸 | 作者. 题名[N]. 报纸名, 出版日期(版次). | 孙八. 资本市场改革[N]. 中国证券报, 2023-05-12(A03). |
| 报告 | 作者. 题名[R]. 出版地: 出版者, 年. | 中国人民银行. 金融稳定报告[R]. 北京: 中国金融出版社, 2023. |
| 标准 | 标准编号 标准名称[S]. 出版地: 出版者, 年. | GB/T 7714—2015 信息与文献 参考文献著录规则[S]. 北京: 中国标准出版社, 2015. |
| 电子资源 | 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL. | 国家统计局. 2023年国民经济和社会发展统计公报[EB/OL]. (2024-02-29)[2024-05-01]. https://www.stats.gov.cn/. |
| 法律法规 | 法律名称[Z]. 公布日期. | 中华人民共和国民法典[Z]. 2020-05-28. |

**作者超过三人**：列前三位后加"等"（中文）/"et al."（英文）。

## 三、作者-年份制（著者出版年制）

正文：`（张三，2023）`；两位作者 `（张三、李四，2023）`；三位以上 `（张三等，2023）`；同作者同年多篇 `（张三，2023a）`、`（张三，2023b）`。

文末文献表按作者拼音/字母排序，年份紧跟作者：

```
张三, 李四. 2023. 数字化转型与企业创新[J]. 经济研究, 58(4): 112-128.
王五. 2022. 公司金融[M]. 3版. 北京: 中国人民大学出版社.
```

## 四、APA 第 7 版（新闻传播、社会学、心理常用）

| 类型 | 格式 | 示例 |
|------|------|------|
| 期刊 | Author, A. A. (Year). Title of article. *Journal Name*, *Volume*(Issue), pages. https://doi.org/xxxx | Zhang, S., & Li, S. (2023). Digital transformation and firm innovation. *Economic Research*, *58*(4), 112–128. |
| 专著 | Author, A. A. (Year). *Title of work* (ed.). Publisher. | Wang, W. (2022). *Corporate finance* (3rd ed.). Renmin University Press. |
| 章节 | Author, A. A. (Year). Title of chapter. In E. Editor (Ed.), *Book title* (pp. xx–xx). Publisher. | |
| 网页 | Author. (Year, Month Day). *Title*. Site. URL | |

正文：`(Zhang & Li, 2023)`；三位以上 `(Zhang et al., 2023)`。

## 五、《法学引注手册》要点

- 正文用**页下注**，编号连续（①②③ 或 1.2.3.，全文统一）。
- 引用专著：`作者：《书名》，出版社年份版，第 X 页。`
- 引用论文：`作者：《文章名》，载《期刊名》年份第 X 期，第 X 页。`
- 引用法条：`《中华人民共和国民法典》第 577 条。`（第一次出现给全称，之后可用简称）
- 引用案例：`参见某某诉某某案，某某人民法院（2023）某民初字第 X 号民事判决书。`
- 转引要写"转引自"，且**能查原文就不要转引**。

---

## 六、芝加哥注释体例（部分历史、哲学刊物）

- 注释（Note）：`作者名, 《书名》（出版地: 出版社, 年份）, 页码。`
- 参考文献（Bibliography）：`作者姓, 名. 《书名》. 出版地: 出版社, 年份。`

---

## 七、体例混用的典型症状（自检用）

1. 正文用上标 `[1]`，文末文献表却按作者拼音排序 → 顺序编码制与著者出版年制混用。
2. 一部分文献有 DOI、一部分没有；一部分有卷期、一部分只有年份 → 录入不统一。
3. 同一本书第一次写"3版"，后面写"第三版"。
4. 期刊名一部分用全称、一部分用简称。
5. 学位论文的文献表与正文编号不连续（删改后未重排）。
6. 脚注里出现"同上"但上一条隔了两页以上。

**修法**：选定一种体例 → 全文重排 → 逐条核对正文与文献表一一对应。

---

## 八、必须提醒用户的三件事

1. **以学院模板为准**。本科生院与各学院的毕业论文格式文件效力高于任何通用体例；本校各院细则可能对字号、行距、参考文献条数另有要求。
2. **不要混用中英文体例**。中文文献按中文体例、英文文献按英文体例是允许的（同一体系内），但整篇的标注方式（上标/夹注/脚注）必须统一。
3. **本科毕业论文通常要求外文文献**。多数学院对参考文献中的外文条目有数量下限，具体条数以学院格式文件为准——不要凭印象说"三篇就够"。
